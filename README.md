## Trackers Bot
Discord bot that automates Trackers Discord servers day-to-day management, handling adding new courses and roles, reaction roles, and much more.

### Requires
- [pyenv](https://github.com/pyenv/pyenv)
- [pre-commit](https://pre-commit.com/)

### Getting Started
```bash
git clone git@github.com:Trackers-Devs/trackers-bot.git
cd trackers-bot
pyenv install
pip install -r requirements.txt
pre-commit install
```

### Running Locally
```bash
python main.py
```
